# Яндекс Диск — WebDAV

Работа с личным Диском (`webdav.yandex.ru`). Один скрипт на stdlib, без зависимостей.

```bash
D=~/.claude/skills/yandex360-disk/scripts/ydisk.py
python3 $D [--account АЛИАС] <команда>
```

## Команды

| Команда | Что делает |
|---|---|
| `ls [path]` | содержимое папки: имя, размер, дата |
| `tree [path] [--depth N]` | дерево на несколько уровней (по умолчанию 2) |
| `find <подстрока> [path] [--depth N]` | поиск по именам, рекурсивно (по умолчанию 3) |
| `space` | занято / свободно / процент |
| `get <remote> [local]` | скачать файл |
| `put <local> <remote> [--confirm]` | загрузить файл |
| `mkdir <path>` | создать папку |

## Загрузка — через гейт

`put` без `--confirm` **ничего не пишет** на Диск: печатает, что и куда пойдёт, и выходит.
Причина — `PUT` по существующему пути перезаписывает файл молча, без корзины и без вопроса.

Порядок: прогнать без `--confirm` → показать пользователю путь и размер → дождаться «го» →
повторить с `--confirm`.

Удаления нет вообще и не будет: снести чужие 217 ГБ одной опечаткой в пути слишком легко.

## Ящики

Алиасы задаются файлом `~/.config/yandex360/accounts.json` — карта «алиас → адрес»:

```json
{ "личный": "you@yandex.ru", "работа": "you@your-domain.ru" }
```

Ключ `default` берётся, когда `--account` не передан. Пароли отдельно: Keychain,
сервис `yandex360-webdav`, account = полный адрес.

## Настройка

Нужен пароль приложения **именно под «Файлы · WebDAV»** — у Яндекса пароли привязаны
к сервису, почтовый или календарный сюда не подойдут.

1. Яндекс ID → Безопасность → Пароли приложений → **Файлы · WebDAV**.
2. ```bash
   security add-generic-password -s yandex360-webdav -a "you@yandex.ru" -w
   ```

⚠️ Пароль агенту не показывать и в файлы скилла не класть.

## Грабли, которые уже учтены

**Прокси роняет запрос.** `ALL_PROXY` из окружения уводит обращение к `webdav.yandex.ru`
в сплит-прокси. Скрипт ходит через `ProxyHandler({})` — мимо прокси. Тот же симптом
у `caldav.yandex.ru` и `neuraldeep.ru`.

**Яндекс отдаёт `<href xmlns="DAV:">` — тег с атрибутом.** Регексп `<href>` его не поймает,
нужен `<href[^>]*>`. Промах даёт не ошибку, а тихую пустоту.

**Кириллица и пробелы в путях.** Папки вида `/УВБ ФТМИ Луценко/` требуют `urllib.parse.quote`
на пути, но не на схеме с хостом. Учтено в `enc()`.

**`find` рекурсивный и упирается в глубину, а не во время.** По умолчанию 3 уровня;
на большом Диске каждый уровень — это ещё пачка PROPFIND. Скрипт печатает, сколько
объектов просмотрел, чтобы было видно охват, а не только находки.
