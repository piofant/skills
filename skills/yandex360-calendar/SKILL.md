# Яндекс Календарь — CalDAV

Чтение личного календаря (`caldav.yandex.ru`). Один скрипт на stdlib, без зависимостей.

```bash
C=~/.claude/skills/yandex360-calendar/scripts/ycal.py
python3 $C [--account АЛИАС] <команда>
```

## Команды

| Команда | Что делает |
|---|---|
| `calendars` | список календарей ящика |
| `today` | события на сегодня |
| `week` | события на 7 дней |
| `events --days N [--past N] [--verbose]` | произвольный диапазон; `--past` захватывает прошлое |

События выводятся сгруппированными по дням, отсортированными по времени, с местом
проведения. `--verbose` добавляет описания.

## Ящики

Алиасы задаются файлом `~/.config/yandex360/accounts.json` — обычная карта «алиас → адрес»:

```json
{ "личный": "you@yandex.ru", "работа": "you@your-domain.ru" }
```

Ключ `default` используется, когда `--account` не передан. Если его нет, а ящиков
несколько — скрипт попросит уточнить, а не выберет наугад. Пароли лежат отдельно:
Keychain, сервис `yandex360-caldav`, account = полный адрес.

## Настройка

Нужен пароль приложения **именно под «Календарь · CalDAV»**. Почтовый пароль сюда
не подойдёт — у Яндекса пароли привязаны к сервису.

1. Яндекс ID → Безопасность → Пароли приложений → **Календарь · CalDAV**.
2. ```bash
   security add-generic-password -s yandex360-caldav -a "you@example-domain.ru" -w
   ```

⚠️ Пароль агенту не показывать и в файлы скилла не класть — скрипт читает Keychain напрямую.

## Грабли, которые уже учтены

**Прокси роняет запрос.** `ALL_PROXY` из окружения уводит обращение к `caldav.yandex.ru`
в сплит-прокси и валит хендшейк. Скрипт ходит через `ProxyHandler({})` — мимо прокси.
Тот же симптом ловился на `neuraldeep.ru`: «работает в шелле, падает в фоне» — это
про окружение, а не про инструмент.

**Яндекс отдаёт `<href xmlns="DAV:">` — тег с атрибутом.** Регексп вида `<href>` его
не поймает, нужен `<href[^>]*>`. На этом парсер списка календарей молчал, возвращая пустоту
вместо ошибки. Учтено.

**В доме календарей лежат не только календари.** Там же `inbox/`, `outbox/` и списки задач
(`todos-*` с `VTODO`). Скрипт фильтрует по `supported-calendar-component-set` = `VEVENT`,
иначе задачи приедут вперемешку со встречами.

**Склейка длинных строк по RFC 5545 съедает пробел — так и надо.** Перенос делается
через CRLF + один пробел, и при разборе этот пробел удаляется как маркер, а не как текст.
Если в собранном названии слова слиплись — виноват генератор ics, не парсер.

**Часовые пояса.** `DTSTART;TZID=...` конвертируется в Europe/Moscow, `...Z` — из UTF,
`VALUE=DATE` помечается как «весь день». Проверено синтетикой на всех трёх формах.

## Что скилл НЕ делает

Только чтение. Создание, правка и удаление событий не реализованы: календарь —
общий с другими людьми артефакт, случайная запись туда видна всем приглашённым.
Понадобится — добавим с гейтом «показать событие целиком → дождаться „го“ → создать».

Задачи (`VTODO`, календарь «Не забыть») намеренно отфильтрованы. Нужны — добавить
отдельной командой, а не мешать со встречами.
