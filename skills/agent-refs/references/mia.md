## Что это
Self-hosted помощница одной семьи в Telegram: личный чат, семейные и внешние группы. Живёт в чате Острикова. TypeScript (Node 24) на Eve 0.40, форк в `vendor/eve` с патчами под тестами (`agent/lib/eve-*-patch.test.ts`). PostgreSQL 17 + pgvector + workflow-world-postgres. Чат и vision — только DeepSeek (`deepseek-flash`, Responses API); голос — Groq Whisper; картинки — цепочка PlusVibe → NeuralDeep → Cloudflare; эмбеддинги — локальный TEI с `sergeyzh/BERTA`. Docker Compose, свой установщик (`scripts/provider-installer`), подписанные релизы, обновление после «да» владельца. ~110k строк TS без тестов и столько же тестов, 147 миграций. Лицензия Apache-2.0 (`LICENSE`, `NOTICE`); скиллы `agent/skills/{pdf,docx,xlsx}` — под своими лицензиями.

**Чем отличается от Осинары:** BERTA вместо multilingual-e5-small; только у Мии есть `person-cards/`, `authored-skills/` + сервис `services/skill-lab`, `improvements/`, `turn-quality/`, `browser/`, `web-search/`, `deepseek/`, `whisper/`, `telegram-reachability/`.

## Сильные практики
1. **Гибридный поиск одним SQL** — `memory-retrieval-repository.ts:193-380`: RRF по трём веткам со своими порогами, retention как множитель, окно HNSW расширяется до нужного числа записей; на нерелевантный запрос — пусто; деградация до слов. Перенос: средне.
2. **Директива `<memory-used>`** — `memory-used-directive.ts`, `memory-used-reinforcement.ts:30`, `prompt/common-fragments.ts:15`: модель отмечает записи, на которые опёрся ответ; подкрепляются только показанные в этом ходе. Даёт метрику «показано → использовано» — прямой вход для эвала по трейсам. Перенос: низко.
3. **Тихий батч-review памяти** — `memory-review/memory-review-prompt.ts:14`, `memory-review-config.ts`: отдельная сессия без ответа в чат, узкий набор инструментов, «только из проверяемых сообщений». README:76: отдельная проверка находила вдвое больше и точнее, чем подшитая к ответу. Перенос: средне.
4. **Слоты с оптимистичной блокировкой и мягкий near-dup** — `memory-slot-supersede.ts:153`, `memory-near-duplicate.ts:111,193`: шлюз не склеивает сам, а предлагает модели `reinforces` / `attribute` / `distinct`. Перенос: средне.
5. **Кэш-дружелюбный контекст** — `telegram-turn-memory-context.ts` (шапка), `config.ts:17-21`: память user-сообщением, системный префикс байт-в-байт одинаковый, окно 160k ради цены. Перенос: низко.
6. **Контракт ошибок инструментов + защита от повторов** — `model-facing-error.ts:83`, `tool-repeat-guard.ts:40`, `instructions.md:51`: при `unknown` побочный эффект не повторяется, одинаковый упавший вызов блокируется. Перенос: низко.
7. **Проверяемое улучшение навыков** — `skill-evaluation.ts`, `skill-selection.ts`, `authored-skill-repository.ts:693`, `services/skill-lab`: доказательства по выходам инструментов, оценка привязана к версии. Перенос: высоко.
8. **Рефлексия без текста людей** — `improvements/turn-evidence.ts:177,196`, `reflection.ts:142,156`: в evidence только имена инструментов и коды ошибок — чат не может отравить бэклог; rate limit. Перенос: средне.
9. **Durable ingress, серии и interjections** — `telegram-durable-ingress.ts:298`, `telegram-message-series.ts`, `turn-interjection/turn-interjection-collector.ts`: сообщения не теряются, несколько подряд — один ответ, «стоп, не Москва» доходит до модели после ближайшего шага. Перенос: средне–высоко.
10. **Handoff при ротации сессии** — `sessions/session-handoff.ts:174`: саммари из таймлайна приложения, показывается один раз. Перенос: низко.
