# Ralph Loop — «один промпт, бесконечный цикл, пока не готово»

Техника Geoffrey Huntley (упакована Anthropic как офиц. плагин `ralph-loop`). Суть: агент запускается на одном и том же промпте снова и снова. Между итерациями память сбрасывается, но на диске остаётся его прошлая работа (файлы, тесты, git history) — она и есть «память». Так задача дожимается итеративно, без ручного перезапуска.

**Ralph vs autoresearch:** Ralph дожимает ОДНУ задачу по фиксированному промпту до завершения (нет численной метрики, нет журнала экспериментов). Autoresearch оптимизирует против измеримой метрики с keep/discard и логом. Если есть число, которое надо двигать → autoresearch. Если «доделай фичу/почини баг до конца» → ralph.

Два пути — выбирай по среде:

| | In-session (Stop-hook) | Standalone CLI |
|---|---|---|
| Где | Claude Code, текущая сессия | любой шелл: Claude CLI / Codex / VPS |
| Механизм | Stop-hook блокирует выход, кормит тем же промптом | внешний `while true` вызывает агента заново |
| Хуки нужны | да (`.claude/settings.json`) | нет |
| Стоп | `--max-iterations` или `<promise>…</promise>` | Ctrl-C, max-iterations, sentinel-файл |
| Видно прогресс | да, в живой сессии | в логах итераций |

## Путь 1 — In-session (Stop-hook)

1. Один раз на проект подключи Stop-hook:
   ```bash
   bash <SKILL_DIR>/scripts/install-hook.sh    # добавит Stop hook в ./.claude/settings.json
   ```
2. Запусти петлю (создаёт `.claude/ralph-loop.local.md` со state):
   ```bash
   bash <SKILL_DIR>/scripts/setup-ralph-loop.sh "Build a REST API for todos" \
        --completion-promise 'ALL TESTS PASS' --max-iterations 30
   ```
3. Работай над задачей. Когда попытаешься выйти — Stop-hook вернёт ТОТ ЖЕ промпт следующей итерации. Ты увидишь прошлую работу в файлах/гите и продолжишь улучшать.

**Стоп только двумя способами:** достигнут `--max-iterations`, ИЛИ выведен `--completion-promise` в тегах `<promise>ТЕКСТ</promise>`.

### КРИТИЧЕСКОЕ ПРАВИЛО honest-promise
Completion-promise можно выводить ТОЛЬКО когда утверждение **полностью и безусловно ИСТИННО**.
- ✗ НЕ выводи ложный promise, чтобы сбежать из петли — даже если кажется, что застрял, задача невозможна или «уже долго».
- ✗ НЕ обходи петлю обманом. Петля рассчитана крутиться, пока promise не станет истинным ЕСТЕСТВЕННО.
- ✓ Если стоит застопориться — promise станет истинным сам, когда задача реально решится. Не форсируй ложью.

Отмена вручную: `/cancel-ralph` или `rm .claude/ralph-loop.local.md`.

## Путь 2 — Standalone CLI (портативный, без хуков)

Оригинальная форма Ralph: внешний цикл вызывает агента headless с одним промптом. Работает где есть CLI агента — Codex, VPS, cron.

1. Положи задачу в `PROMPT.md` (живёт в репо, агент может её же и редактировать — план остаётся между итерациями).
2. Запусти:
   ```bash
   # Claude CLI:
   bash <SKILL_DIR>/scripts/ralph-run.sh --prompt PROMPT.md --max 50 --agent claude
   # Codex:
   bash <SKILL_DIR>/scripts/ralph-run.sh --prompt PROMPT.md --max 50 --agent codex
   ```
3. Стоп: `Ctrl-C`, достигнут `--max`, или `touch .ralph-stop` (sentinel).

Паттерн внутри: каждая итерация — свежий контекст, читает PROMPT.md + текущее состояние репо, делает шаг, коммитит. Хорошие промпты для Ralph включают: «изучи прошлую работу в репо и git log перед началом», «делай маленький проверяемый шаг», «гоняй тесты», «коммить с осмысленным сообщением», «обнови PROMPT.md / fix_plan.md прогрессом».

---

## Хороший Ralph-промпт (рекомендации)
- Чёткое определение «готово» (которое можно превратить в honest completion-promise).
- «Сначала прочитай свою прошлую работу (файлы, git log) — не начинай с нуля.»
- «Один маленький проверяемый шаг за итерацию, затем тесты, затем commit.»
- Ведение `fix_plan.md` / чек-листа, который переживает итерации.
- Явные границы: что НЕ трогать.

## Анти-паттерны
- ❌ Ложный completion-promise ради побега (см. honest-promise).
- ❌ Бесконечный цикл без `--max-iterations` на дорогих задачах — задашь лимит.
- ❌ Промпт без критерия завершения — петля не поймёт, когда стоп.
- ❌ Игнорировать прошлую работу и начинать заново каждую итерацию.

## Связанные
- `autoresearch` — петля с измеримой метрикой и журналом keep/discard.
- Офиц. плагин `ralph-loop@claude-plugins-official` — даёт слэш-команды `/ralph-loop`, `/cancel-ralph` в Claude Code (этот скилл — портативная скилл-форма той же техники).
