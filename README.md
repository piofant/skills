# Агентские скиллы piofant

Скиллы, которыми я пользуюсь каждый день: ресёрч, презентации, редактура,
автоматизация. Работают в Claude Code и Codex.

**Витрина: [piofant.github.io/skills](https://piofant.github.io/skills/)** — там
те же скиллы разобраны по персонажам: у каждого своя работа и набор приёмов,
можно ткнуть в любого и посмотреть, что он умеет.

<sub>*English: personal agent-skill pack — research pipelines, deck building,
Russian-language editing, automation loops. Most skills are Russian-first;
`deep-thinking`, `skill-scout`, `find-skills`, `ralph-loop`, `autoresearch` and
`market-analysis` are language-agnostic.*</sub>

## Ресёрч и знание

- `research` — базовый цикл исследования: план, оси сравнения, outline
- `research-deep` — глубокий проход по каждому пункту готового outline
- `research-report` — сборка финального отчёта из артефактов
- `research-writeup` — доказательная часть отчёта: проверка утверждений по
  первоисточникам, таблица статусов с сохранёнными REFUTED-строками, цитаты
  с русским пересказом
- `research-add-fields` / `research-add-items` — расширение схемы и состава
  идущего исследования
- `tg-research` — ресёрч по своим телеграм-чатам: сбор через MCP, параллельные
  агенты, отчёт
- `deep-thinking` — продумывание задачи до кода: разбор на 5–15 аспектов, по
  эксперту на аспект, на выходе design-документ с планом
- `blog-search` — семантический поиск по своим постам: «писал ли я уже про X»,
  подборки по теме, похожие посты для перелинковки, аудит тегов

## Деки и презентации

- `dark-deck-builder` — тёмные минимал-деки с активными заголовками на pptxgenjs
- `board-deck-builder` — структура борд- и инвестор-апдейта
- `pitch-deck-builder` — нарратив и порядок слайдов для питча
- `product-case-deckmaker` — продуктовый кейс от постановки до деки
- `mckinsey-style-visualization` — консалтинговая визуализация и композиция слайда
- `report-styling` — аналитические MD-отчёты: активные заголовки, графики вместо
  таблиц, семь шаблонов чартов
- `md-to-pdf-deck` — markdown → PDF: презентация (A4 landscape, слайд на H2) или
  лонгрид, тёмная тема, mermaid, диалоговые цитаты
- `scientific-slides` — доклады и защиты: структура, тайминг, визуальная проверка
- `magistratura-interview-deck` — дек на 3-минутное собеседование в магистратуру
- `itmo-report` — отчёты и презентации ИТМО в LaTeX/PPTX

## Тексты

- `humanizer-ru` — убирает признаки AI-генерации и канцелярит из русского текста
- `ru-text` — стиль, типографика, UX- и деловая редактура
- `pioblog-tov` — переписывает текст голосом моего блога
- `roman-mikhailov-tov` — голосом Романа Михайлова: математик, который посреди
  лекции уходит в байки, и всё это на ровном лекторском серьёзе
- `motivation-letter` — **проверяет** готовое мотивационное письмо перед подачей:
  структура под конкретный конкурс, каталог красных флагов, лимит знаков, связь
  с описанием программы. Письмо за автора не пишет — сгенерированный текст
  приёмная комиссия считывает быстрее, чем кажется

## Инструменты

- `skill-scout` — поиск скиллов по всем реестрам сразу: дедуп зеркал, оценка
  доверия по тирам, security-скан, установка под нужный источник
- `find-skills` — установка скиллов из открытой экосистемы (`npx skills`)
- `ralph-loop` — гонять агента в while-true цикле по одному промпту, пока задача
  действительно не сделана
- `autoresearch` — петля «замерь → поменяй → замерь → оставь лучшее»
- `market-analysis` — MECE, SCPR, RICE, разбор рынка
- `notebooklm` — работа с Google NotebookLM: блокноты, источники, подкасты

## MCP-серверы

`mcp/blog-search` — семантический и тег-поиск по постам блога. Эмбеддит запрос
через OpenRouter `text-embedding-3-small`, считает cosine к локальному
`index.json`, тела постов читает прямо из `.md`.

Два входа:

- **CLI** — `node cli.mjs search "запрос"`. Без зависимостей, только встроенные
  модули Node. Команды: `search`, `similar`, `tags`, `tag`, `get`, `check`,
  `sync`, у каждой есть `--json`. Индекс досинкивается сам перед поиском,
  руками звать `sync` не нужно.
- **MCP-сервер** — `server.mjs`, тулы `search_posts`, `list_by_tag`, `get_post`.
  Требует `npm install` и читает индекс один раз при старте, поэтому новых
  постов не увидит до перезапуска. CLI в этом смысле надёжнее.

Нужен свой `OR_LLM_API_KEY` и первый прогон `node build-index.mjs` — индекс
и `.env` в репозиторий не попадают.

## Установка

Скопировать нужную папку из `skills/` в каталог скиллов своего агента:

```bash
cp -R skills/deep-thinking ~/.claude/skills/     # Claude Code
cp -R skills/deep-thinking ~/.codex/skills/      # Codex
```

Скиллы самодостаточны: у каждого свой `SKILL.md`, при необходимости — скрипты
и референсы рядом.

## Про содержимое

Здесь только инструкции скиллов и вспомогательные файлы. Ключей, токенов,
cookies и рабочих артефактов тут нет и быть не должно.

Часть скиллов описывает, как авторизоваться во внешних сервисах (например,
Google OAuth для NotebookLM) — но живых учёток в репозитории не хранится.
